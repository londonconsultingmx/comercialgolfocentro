# Glosario

## Términos LCG

| Término | Definición |
|---|---|
| **AAA (clasificación LCG)** | Empresa que factura más de USD $30M anuales |
| **AA (clasificación LCG)** | Empresa que factura entre USD $20M y $30M anuales |
| **Etapa del lead** | Estado del lead en HubSpot: "No Cumple perfil", "Lead Calificado", "Lead con Cita", "Pre-DX", "Cliente Anterior", "Cliente" |
| **Pre-DX** | Antesala a Diagnóstico — empresa en proceso de cierre |
| **Tubería Alta** | Pipeline principal de HubSpot (`default`) |
| **Tubería MW** | Pipeline secundario (`692654695`) |
| **Owner** | Propietario del registro en HubSpot |
| **Cliente Anterior** | Empresa que fue cliente histórico — oportunidad de re-engagement |
